## 📊 深度学习核心概念详解

### 1️⃣ **网络结构**
```
输入图像 (28×28)
    ↓
[卷积层1] 提取低级特征（边缘、纹理）
    ↓
[卷积层2] 提取高级特征（形状、模式）
    ↓
[池化层] 降维、增强不变性
    ↓
[全连接层] 特征整合、分类决策
    ↓
输出 (10个数字的概率)
```

### 2️⃣ **数据处理**
```python
# 标准化公式
x_norm = (x - mean) / std

# MNIST参数
mean = 0.1307  # 全局均值
std = 0.3081   # 全局标准差
```

**作用**：
- 加速收敛
- 稳定训练
- 防止梯度爆炸

### 3️⃣ **损失函数（Loss）**
```python
loss = -log(P(正确类别))
```

**含义**：
- 损失越小 → 预测越准确
- 损失 = 0.1 很好，损失 = 2.3 很差
- 训练目标：最小化损失

### 4️⃣ **优化器（Optimizer）**

| 优化器 | 特点 | 使用场景 |
|--------|------|---------|
| SGD | 经典，需要调参 | 视觉任务 |
| Adam | 最常用 | 通用 |
| Adadelta | 自适应，本项目使用 | 参数调优难 |

### 5️⃣ **梯度下降**
```python
# 数学表达
参数_新 = 参数_旧 - 学习率 × 梯度

# PyTorch代码
optimizer.step()  # 自动完成上述计算
```

**直观理解**：
- 梯度 = 山坡的陡峭程度
- 学习率 = 每次下山的步长
- 目标 = 找到山谷最低点（最小损失）

### 6️⃣ **反向传播**
```python
loss.backward()  # PyTorch自动计算所有梯度
```

**内部原理**：
1. 记录前向传播的计算图
2. 从损失开始，逐层向前计算梯度
3. 使用链式法则：∂L/∂x = ∂L/∂y × ∂y/∂x
4. 将梯度存储在每个参数的 `.grad` 属性中

### 7️⃣ **TensorBoard可视化**

**查看内容**：
- 📉 损失曲线：观察是否收敛
- 📈 准确率曲线：评估性能提升
- 🎓 学习率：监控调度策略
- 🏗️ 模型结构：理解网络架构
- 📊 参数分布：检测异常
