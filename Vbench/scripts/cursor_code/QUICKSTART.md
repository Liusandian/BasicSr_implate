# 视频对比工具 - 快速入门

## 🚀 5分钟快速开始

### 步骤1: 安装依赖（2分钟）

**Windows:**
```bash
# 双击运行（或在命令行执行）
run_video_compare.bat
```

**macOS/Linux:**
```bash
# 先给脚本执行权限
chmod +x run_video_compare.sh

# 运行启动脚本
./run_video_compare.sh
```

**或手动安装：**
```bash
pip install -r requirements_video_tool.txt
```

---

### 步骤2: 准备测试视频（1分钟）

创建以下文件夹结构：

```
my_videos/
├── Camera_A/
│   ├── test_01.mp4
│   └── test_02.mp4
└── Camera_B/
    ├── test_01.mp4
    └── test_02.mp4
```

**提示：** 如果没有现成视频，可以：
- 用手机拍摄几个测试视频
- 从网上下载示例视频
- 使用现有的视频文件

---

### 步骤3: 运行程序（30秒）

```bash
python video_compare_tool.py
```

---

### 步骤4: 对比视频（1分钟）

1. **选择文件夹**
   - 点击左侧 "选择文件夹"
   - 选择 `my_videos` 目录

2. **选择对比组**
   - 按住 Ctrl 选择 "Camera_A" 和 "Camera_B"

3. **设置布局**
   - 右上角选择 "1x2" 或 "2x2"

4. **加载视频**
   - 点击 "加载选中的视频"

5. **开始播放**
   - 点击 "▶ 播放" 按钮

---

## 💡 常用操作

### 播放控制

| 操作 | 按钮/快捷键 |
|------|------------|
| 播放/暂停 | 点击 "▶ 播放" / "⏸ 暂停" |
| 下一个视频 | 点击 "下一个 ⏭" |
| 上一个视频 | 点击 "⏮ 上一个" |
| 跳转进度 | 拖拽进度条 |
| 重置到开始 | 点击 "🔄 重置" |

### 布局切换

- **2个视频**: 选择 `1x2` (横排) 或 `2x1` (竖排)
- **4个视频**: 选择 `2x2`
- **6个视频**: 选择 `2x3` 或 `3x2`
- **9个视频**: 选择 `3x3`

### 质量调节

- **高质量**: 设置显示高度为 `1080` 或 `1440`
- **中质量**: 设置为 `720`
- **快速预览**: 设置为 `480`

## ⚠️ 注意事项

### 性能优化

如果遇到卡顿：
1. ✅ 降低 "显示高度" (改为720p)
2. ✅ 减少同时播放的视频数量
3. ✅ 关闭其他占用资源的程序
4. ✅ 使用SSD存储视频文件

### 兼容性

- ✅ 推荐使用 MP4 格式（H.264编码）
- ✅ 确保所有对比视频帧率一致
- ⚠️ 避免视频文件名包含特殊字符
- ⚠️ 路径不要包含中文（可能导致问题）

### 硬件建议

最低配置：
- CPU: 4核
- 内存: 8GB
- 显卡: 集成显卡

推荐配置：
- CPU: 6核+
- 内存: 16GB+
- 显卡: 独立显卡

## 🐛 故障排除

### 问题1: 无法打开程序

**错误信息**: `No module named 'PyQt5'`

**解决方法**:
```bash
pip install PyQt5 opencv-python numpy
```

---

### 问题2: 视频无法加载

**可能原因**: 视频编码不支持

**解决方法**:
```bash
# 安装完整版OpenCV
pip uninstall opencv-python
pip install opencv-contrib-python
```

---

### 问题3: 播放很卡

**解决方法**:
1. 降低显示高度到 720p
2. 减少视频数量（如4个改为2个）
3. 使用较低分辨率的视频

---

### 问题4: 视频不同步

**原因**: 视频帧率不一致

**解决方法**: 使用FFmpeg统一帧率
```bash
ffmpeg -i input.mp4 -r 30 output.mp4
```
