## 🚀 场景1: 草地纹理抖动评测

### 目标
对比5款相机在草地场景下的纹理稳定性。

### Step 1: 快速评测（使用Flicker Penalty）

```bash
# 进入脚本目录
cd scripts/v\'ben\'ch_for_flickering

# 方法1: 对比多个相机
python eval_flicker_penalty.py \
    --compare \
    --camera "Insta360 X3":"../../test_videos/grass/insta360_grass.mp4" \
    --camera "Sony ZV-E10":"../../test_videos/grass/sony_grass.mp4" \
    --camera "Canon R6 II":"../../test_videos/grass/canon_grass.mp4" \
    --camera "Huawei P80":"../../test_videos/grass/huawei_grass.mp4" \
    --camera "iPhone 16 Pro":"../../test_videos/grass/iphone16_grass.mp4" \
    --output ../../results/grass_fp_comparison.json
```

### Step 2: 多维度综合评测

```bash
# 使用标准评测模式（5个维度）
python texture_jitter_eval.py \
    --video_dir ../../test_videos/grass \
    --mode standard \
    --output_dir ../../results/grass
```

这将评测以下维度：
- Temporal Flickering (时序闪烁)
- Motion Smoothness (运动平滑度)
- Imaging Quality (成像质量)
- Background Consistency (背景一致性)
- Overall Consistency (整体一致性)

**预期耗时：** 约15-20分钟（5个视频）

### Step 3: 生成评测报告

```bash
# 生成Markdown报告
python analyze_results.py \
    --results_dir ../../results/grass \
    --output ../../reports/grass_report.md \
    --show_chart
```

**报告内容包括：**
- 各维度评测结果汇总表格
- 相机排名对比
- 详细的每个视频结果
- ASCII对比图表

### 示例1: 自动场景分类评测

```python
#!/usr/bin/env python3
"""
根据视频动态程度自动选择评测策略
"""

import sys
import os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), '..', '..'))

from vbench import VBench

def auto_eval(video_path, output_dir='results'):
    """自动评测单个视频"""
    
    # 初始化VBench
    vbench = VBench('cuda', 'vbench/VBench_full_info.json', output_dir)
    
    # 1. 先评估动态程度
    print("评估动态程度...")
    dynamic_score, _ = vbench.evaluate(
        videos_path=video_path,
        name='dynamic_check',
        dimension_list=['dynamic_degree'],
        mode='custom_input'
    )
    
    print(f"Dynamic Degree: {dynamic_score:.4f}")
    
    # 2. 根据动态程度选择评测维度
    if dynamic_score < 0.3:
        # 静态场景
        print("检测到静态场景，使用静态评测方案...")
        dimensions = [
            'temporal_flickering',
            'imaging_quality',
            'background_consistency'
        ]
    elif dynamic_score < 0.6:
        # 中等运动
        print("检测到中等运动场景，使用混合评测方案...")
        dimensions = [
            'temporal_flickering',
            'motion_smoothness',
            'imaging_quality'
        ]
    else:
        # 强烈运动
        print("检测到强烈运动场景，使用运动评测方案...")
        dimensions = [
            'motion_smoothness',
            'overall_consistency'
        ]
        # 对于运动场景，额外使用Flicker Penalty
        print("注意：运动场景建议使用 eval_flicker_penalty.py")
    
    # 3. 执行评测
    print(f"评测维度: {dimensions}")
    results = {}
    
    for dimension in dimensions:
        score, _ = vbench.evaluate(
            videos_path=video_path,
            name=f'auto_{dimension}',
            dimension_list=[dimension],
            mode='custom_input'
        )
        results[dimension] = score
        print(f"  {dimension}: {score:.4f}")
    
    return results

if __name__ == '__main__':
    if len(sys.argv) < 2:
        print("用法: python auto_eval.py <video_path>")
        sys.exit(1)
    
    video_path = sys.argv[1]
    results = auto_eval(video_path)
    
    print("\n评测完成！")
    print(f"综合得分: {sum(results.values())/len(results):.4f}")
```

### 示例2: 生成对比矩阵

```python
#!/usr/bin/env python3
"""
生成多相机多场景对比矩阵
"""

import json
import numpy as np
import pandas as pd

def generate_comparison_matrix(results_dir='results'):
    """生成对比矩阵"""
    
    cameras = ['Insta360', 'Sony', 'Canon', 'Huawei', 'iPhone16']
    scenes = ['grass', 'night', 'glass', 'motion']
    
    # 创建矩阵
    matrix = {}
    
    for scene in scenes:
        matrix[scene] = {}
        
        for camera in cameras:
            # 读取该相机在该场景的评测结果
            result_file = f"{results_dir}/{scene}/{camera}_results.json"
            
            try:
                with open(result_file) as f:
                    data = json.load(f)
                    # 计算平均分
                    scores = [v['average_score'] for v in data['results'].values() 
                             if v.get('average_score') is not None]
                    avg_score = np.mean(scores) if scores else 0
                    matrix[scene][camera] = avg_score
            except:
                matrix[scene][camera] = 0
    
    # 转换为DataFrame
    df = pd.DataFrame(matrix).T
    
    print("\n=== 相机性能对比矩阵 ===")
    print(df.to_string())
    
    # 保存为CSV
    df.to_csv('comparison_matrix.csv')
    print("\n✓ 矩阵已保存: comparison_matrix.csv")
    
    # 计算综合排名
    avg_scores = df.mean(axis=0).sort_values(ascending=False)
    
    print("\n=== 综合排名 ===")
    for rank, (camera, score) in enumerate(avg_scores.items(), 1):
        medal = "🥇" if rank == 1 else "🥈" if rank == 2 else "🥉" if rank == 3 else f"{rank}."
        print(f"{medal} {camera}: {score:.4f}")
    
    return df

if __name__ == '__main__':
    generate_comparison_matrix()
```

### 示例3: 实时评测监控

```python
#!/usr/bin/env python3
"""
实时监控评测进度
"""

import os
import time
from pathlib import Path
from watchdog.observers import Observer
from watchdog.events import FileSystemEventHandler

class EvaluationMonitor(FileSystemEventHandler):
    """评测结果监控器"""
    
    def __init__(self, results_dir):
        self.results_dir = Path(results_dir)
        self.processed_files = set()
    
    def on_created(self, event):
        if event.is_directory:
            return
        
        if event.src_path.endswith('.json'):
            print(f"\n新的评测结果: {event.src_path}")
            
            # 延迟读取，确保文件写入完成
            time.sleep(1)
            
            try:
                import json
                with open(event.src_path) as f:
                    data = json.load(f)
                
                # 提取关键信息
                if 'results' in data:
                    print("  评测结果概览:")
                    for dim, result in data['results'].items():
                        if isinstance(result, dict):
                            score = result.get('average_score', 'N/A')
                            print(f"    {dim}: {score}")
                
                self.processed_files.add(event.src_path)
                
            except Exception as e:
                print(f"  无法读取: {e}")

def monitor_evaluation(results_dir='results'):
    """监控评测目录"""
    
    print(f"开始监控评测目录: {results_dir}")
    print("按 Ctrl+C 停止监控\n")
    
    event_handler = EvaluationMonitor(results_dir)
    observer = Observer()
    observer.schedule(event_handler, results_dir, recursive=True)
    observer.start()
    
    try:
        while True:
            time.sleep(1)
    except KeyboardInterrupt:
        observer.stop()
        print("\n监控已停止")
    
    observer.join()

if __name__ == '__main__':
    import sys
    results_dir = sys.argv[1] if len(sys.argv) > 1 else 'results'
    monitor_evaluation(results_dir)
```

## 💡 最佳实践

### 1. 视频拍摄规范

```markdown
标准测试流程：

1. 环境准备
   - 统一光线条件
   - 确定拍摄位置和角度
   - 预设相机参数

2. 拍摄要求
   - 时长: 10-15秒
   - 分辨率: 1080p或4K
   - 帧率: 30fps或60fps
   - 曝光: 固定曝光（避免自动曝光）
   - 对焦: 固定对焦

3. 场景要求
   - 草地: 选择纹理丰富的草地，避免强风
   - 夜景: 保持一致的环境光线
   - 玻璃: 选择反射明显但不过曝的区域
   - 运动: 保持一致的运动速度和轨迹

4. 命名规范
   格式: {相机名}_{场景}_{日期}.mp4
   例如: canon_grass_20260106.mp4
```

### 2. 评测流程建议

```markdown
推荐的评测流程：

Phase 1: 快速筛选 (1小时)
  - 使用FP快速评测所有视频
  - 识别明显的差异
  - 确定需要深入分析的视频

Phase 2: 详细评测 (3-4小时)
  - 对筛选出的视频进行多维度评测
  - 使用standard模式
  - 记录各维度详细数据

Phase 3: 分析报告 (1-2小时)
  - 生成各场景的评测报告
  - 创建对比矩阵
  - 撰写总结和建议
```

### 3. 结果解读技巧

```markdown
综合评分计算：

1. 场景权重
   grass:  30%
   night:  30%
   glass:  20%
   motion: 20%

2. 维度权重（静态场景）
   flicker_penalty:        0.40
   temporal_flickering:    0.30
   imaging_quality:        0.20
   background_consistency: 0.10

3. 维度权重（运动场景）
   motion_smoothness:      0.50
   flicker_penalty:        0.30
   overall_consistency:    0.20

4. 计算公式
   综合分 = Σ(场景分 × 场景权重)
   场景分 = Σ(维度分 × 维度权重)
```
